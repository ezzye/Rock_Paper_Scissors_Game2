What the review changed

FindingBeforeFixed
Known default signing secretThe server started with a published development secret when no environment secret was supplied.Startup rejects missing, blank or known-default secrets. Configuration uses the app’s own signing secret.
Plaintext bot moveButton values disclosed the supposedly hidden move; an HMAC did not conceal it.The move remains in server memory. Buttons carry an unpredictable round ID and the player’s choice.
Reusable, unscoped tokensTokens could be reused and did not bind play to a specific player, workspace, channel or expiry.Rounds are bound to all three identities, expire after ten minutes and are consumed once.
Malformed interaction crashesUnexpected JSON shapes and non-string action values could reach unchecked operations.Payload and action validation, controlled errors, request-body limits and regression coverage guard the route.
Non-numeric timestampsA non-numeric timestamp could escape the age check through a NaN comparison.Timestamp and signature formats are checked before the five-minute window and constant-time signature comparison.
Block Kit results in ACK onlyThe result was returned in the interaction acknowledgement, without the required message update flow.The handler acknowledges promptly, then posts the update to a validated Slack response_url.
Missing tests, docs and accessibilityNo automated suite; setup and operational limits were incomplete; browser results lacked live announcements.Regression tests, CI configuration, setup notes and limits; visible focus, live results, reduced-motion support and HTML save/share controls.

Evidence and remaining checks

Local checks passed

All 35 Node tests passed on Node 26. They cover game outcomes, signature checks, move secrecy, ownership, expiry, single use, malformed requests, body limits and delivery failures.

The test transport uses real Node request/response streams in process. A local socket listener was blocked by the execution environment, so the real HTTP transport was verified in GitHub Actions instead.

Checks still required

GitHub Actions passed on Node 22 and 24, with all 35 tests passing in both memory and HTTP modes. View the successful test run. No live Slack workspace installation or end-to-end message delivery has been tested.

Browser game and save/share branches passed JavaScript VM checks. Browser file-URL policy blocked opening the demo for visual and actual offline-download checks; those checks remain unverified.

Run it as a small, single-process app

Pending rounds live in memory for ten minutes, with a maximum of 10,000. Restarting invalidates them. Run one process; multiple instances need shared state or suitable routing.

A played round is consumed before its message update is delivered. If delivery fails, start again with /rps. The game has no persistent Slack scores and assumes the server chooses fairly.
